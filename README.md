<h1>🛒 Amazon Website Clone</h1>

<h2> 🌐 About the Project </h2>

Welcome to my Amazon Website Clone! This project is a front-end recreation of Amazon's website, developed using HTML5 and CSS3.<br><br>The goal of this project was to recreate Amazon's familiar shopping interface while strengthening my front-end development skills and understanding of modern website layouts.

<h2>✨ Features</h2>

- 🎨 Amazon-inspired user interface.
- 🔍 Stylish search bar.
- 🧭 Navigation bar with multiple categories.
- 🛍️ Product sections and shopping cards.
- 🖼️ Attractive banners and product layouts.
- 📱 Clean and organized webpage design.
- 📌 Well-structured footer section.


<h2>🛠️  Technologies Used</h2>

- <b>HTML5<b> – To build the structure of the website.
- <b>CSS3<b> – To create the design, styling, and layouts.
